# Report schema

## Summary

- Allowed origin
- Requests used / request limit
- Stop reason and unvisited areas
- Scope or robots exclusions

## Inventory table

| Type | Path or endpoint | Method | Input location | Parameter | Observed source | HTTP status |
|---|---|---|---|---|---|---:|

## Required conclusions

1. List unique same-origin paths and endpoints supported by observed evidence.
2. List forms and inputs with method, action, field name, and input location.
3. List API paths supported by HTML or JavaScript evidence.
4. Record the exact source that exposed each item; do not invent or brute-force paths.
5. List external boundaries without visiting them.
6. Clearly label confirmed facts, inferences, and unverified items.
