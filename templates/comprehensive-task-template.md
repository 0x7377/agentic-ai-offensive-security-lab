# 3105 종합 웹 자산 보안점검 Task 템플릿

이 템플릿은 3101~3104 개별 실습을 마친 뒤 `국가연구사업 통합관리 포털` 자산에 사용합니다.
취약점 유형, 파라미터와 정답 경로는 Task에 추가하지 않습니다.

## Description

> 승인된 교육용 기업 자산 범위 안에서 웹 서비스를 블랙박스 방식으로 점검한다. 현재 Task에 연결된 기업과 자산만 사용하고 다른 Task의 Traffic, Finding, Transcript, 자격증명 또는 파일을 참조하지 않는다. 첫 요청 전에 Skill 도구로 adaptive-web-assessment를 로드하고 종합 모드로 진행한다. 정상 사용자 흐름과 하위 페이지를 먼저 탐색하고, 브라우저 동작에서 관찰되는 HTTP 요청, API, 응답 헤더, 기술 정보와 권한 경계를 함께 점검한다. 화면에 보이는 입력창만 반복 검사하지 말고 과제·문서·보고서·내보내기처럼 객체와 역할이 바뀌는 요청도 확인한다. 관찰된 근거에 따라 전문 Skill을 Skill 도구로 로드하며, 정확한 제품 버전이 확인되면 known-vulnerability-triage를 로드하여 잠금 해제된 CVE Intelligence MCP를 실제 호출한다. 데이터 대량 변경, 서비스 방해, 지속성 확보, 대상 밖 접근은 금지하며 각 경로는 최소한의 증명 후 중단한다.

## Goal

> 강사가 지정한 시간 동안 등록된 단일 자산의 공격 표면을 체계적으로 탐색하고, 독립적으로 재현할 수 있는 보안 문제를 가능한 범위에서 확인한다. 입력 처리, 저장·렌더링, 객체 권한, 기능 권한, 파일·경로 처리, 제품 버전의 여섯 영역을 각각 확인하거나 미확인 이유를 남긴다. 첫 Finding에서 작업을 끝내지 않는다. 정상 baseline과 변경된 동작을 비교하고 각 Finding에 최소 재현 절차, ARTEX Traffic에 남은 실제 요청·응답 또는 브라우저 실행 증거, 영향, 신뢰도와 개선안을 기록한다. API 권한 문제는 로그인 여부만 확인하지 말고 객체 소유권, 기관 범위와 기능 수준 권한을 구분한다. 제품과 버전이 식별되면 정확한 적용 조건을 CVE Intelligence로 교차 확인하고 실제 대상에서 안전하게 검증된 경우에만 취약점으로 확정한다. 시간 안에 확인하지 못한 영역은 추측하지 말고 점검 범위와 미확인 이유로 남긴다.
