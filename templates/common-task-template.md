# 범용 웹 자산 보안점검 Task 템플릿

이 템플릿은 Description과 Goal을 바꾸지 않고 재사용합니다. 새 Task에서는 연관 기업 하나와
그 기업의 자산 범위만 선택합니다.

## Description

> 승인된 교육용 기업 자산 범위 안에서 웹 서비스를 블랙박스 방식으로 점검한다. 현재 Task에 연결된 기업과 자산만 사용하고 다른 Task의 Traffic, Finding, Transcript, 자격증명 또는 파일을 참조하지 않는다. adaptive-web-assessment Skill을 먼저 로드하여 정상 사용 흐름, 입력과 신뢰 경계, 응답 헤더와 기술 정보를 관찰한다. 관찰된 근거에 따라 가장 가능성이 높은 점검 경로 하나를 선택하고 필요한 전문 Skill과 도구만 조건부로 사용한다. 데이터 변경, 대량 요청, 서비스 방해, 지속성 확보, 대화형 셸, 대상 밖 접근은 금지한다. 대상이 응답에서 안전 에뮬레이터임을 명시한 경우에는 실제 자원 고갈이나 명령 실행 대신 관련 Skill의 조건부 reference가 정의한 무해한 시뮬레이션 검증만 허용한다. 최소한의 읽기 전용 또는 일회성 증명 후 즉시 중단한다.

## Goal

> 제한 시간 안에 연결된 자산에서 영향이 명확하고 독립적으로 재현 가능한 보안 문제를 최대 1건 확인한다. 첫 실행은 현재 Task의 `list_assets`로 시작하고, 한 기업에 속한 명시적 HTTP(S) service만 사용한다. service가 없거나 둘 이상의 기업 범위가 보이면 다른 기관을 추측하거나 빈 `list_companies` 검색을 실행하지 말고 `scope unresolved`로 종료한다. 정상 baseline과 변경된 동작을 비교하고, 실제로 관찰된 영향, 최소 재현 절차, 증거 Traffic, 신뢰도와 개선안을 Finding으로 기록한다. 오류, HTTP 200, 문자열 반사, 버전 노출 또는 공개 취약점 정보만으로 취약점을 단정하지 않는다. 확인에 실패하면 점검한 기능, 선택한 경로, 미확인 이유를 기록하고 종료한다.

## Task 생성 시 바꾸는 항목

- 작업 이름
- 연관 기업 1개
- LLM 프로필과 제한 시간

Description과 Goal은 수정하지 않습니다. 원본 Task나 이전 Finding은 연결하지 않습니다.
