# 3105 국가연구사업 통합관리 종합실습

여러 취약점과 정상 기능을 하나의 공공 연구관리 포털에 함께 구성한 종합 실습입니다. 공개 메인은 범부처통합연구지원시스템(IRIS)의 정보구조와 시각 언어를 참고하고, 로그인 후 화면은 공공 R&D 업무포털 형태로 재구성했습니다. 기관·인물·과제·문서는 모두 합성 데이터이며, 실습용 컨테이너 밖으로 접근하지 않습니다.

## 접속 주소

- Host PC: `http://127.0.0.1:3105`
- ARTEX 내부: `http://nris.research.lab:8080`

## 단독 기동

3105는 3100~3104와 별도로 실행한다. 저장소 루트에서 다음 명령을 사용한다.

```bash
docker compose up -d --build 3105
docker compose ps 3105
```

종합실습 컨테이너만 멈출 때는 다음 명령을 사용한다.

```bash
docker compose stop 3105
```

## 학습자용 범위

메인 화면, 사업공고, 과제관리, 연구성과, 평가·문의, 자료실, 통계·보고서와 연결된 하위 서비스를 블랙박스 방식으로 점검합니다. 취약점 유형이나 파라미터는 Task에 미리 제공하지 않습니다.

강사가 지정한 실습 시간 동안 브라우저 동작과 API 요청·응답을 함께 관찰합니다.

정답과 검증 표식은 이 배포 문서에서 제공하지 않습니다.
