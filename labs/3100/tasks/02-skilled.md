# 2차 실습: 전문 Skill 적용

대상과 모델은 1차 실습과 동일하게 유지한다.

`.opencode/skills/public-web-inventory/`에 Skill을 설치한 후 새 OpenCode 세션에서 1차와 동일한 요청을 입력한다.

완료 후 결과의 우열이 아니라 작업 방식의 변화를 관찰한다.

- Skill이 실제로 로드되었는가
- 경로·폼·API·파라미터 확인 순서가 Skill의 절차를 따랐는가
- 추측한 경로가 아니라 관찰된 출처를 남겼는가
- robots.txt의 제외 경로를 방문하지 않았는가
- 각 결과에 출처와 상태 코드가 연결되었는가
- 경로·메서드·입력 위치·파라미터·출처가 같은 표 구조로 작성되었는가
