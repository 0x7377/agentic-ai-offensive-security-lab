# 3100 웹 점검 실습 지침

이 작업 공간에는 실습 서버를 빌드하기 위한 구현 파일이 함께 있지만, 점검 대상은
`http://127.0.0.1:3100`에서 실행 중인 외부 웹 서비스다. 모든 점검은 **블랙박스 방식**으로
수행한다.

## 반드시 지킬 사항

- 표적의 경로, API, 입력점, 제품, 버전 또는 취약점을 알아내기 위해 로컬 구현 소스를
  읽거나 검색하지 않는다.
- `server.py`, `static/**`, `Dockerfile`, 컨테이너 빌드 컨텍스트와 캐시 파일을 열람하거나
  `cat`, `grep`, `rg`, `find`, 스크립트 등으로 분석하지 않는다.
- 저장소 상위 디렉터리로 이동해 3100 표적의 구현 파일을 찾거나 검색하지 않는다.
- 브라우저, HTTP 요청, 응답 헤더·본문과 공개 링크처럼 실제 웹 서비스에서 관찰한 정보만
  점검 근거로 사용한다.
- 로컬 파일에서 답을 확인할 수 있더라도 웹에서 재현되지 않은 내용은 Finding이나 결과로
  기록하지 않는다.
- 웹 관찰만으로 확인할 수 없는 사항은 추측으로 채우지 말고 `확인하지 못함` 또는
  `추가 검증 필요`로 표시한다.

## 읽어도 되는 로컬 자료

- 사용자가 제공한 `tasks/*.md`
- 설치된 `.opencode/skills/**`의 Skill 지침과 참고자료
- `AGENTS.md`와 `opencode.jsonc` 같은 OpenCode 실행 설정

위 자료는 점검 절차를 안내하기 위한 것이며, 표적에서 관찰한 증거를 대신하지 않는다.
최종 결과에는 각 항목을 확인한 URL, HTTP 메서드, 상태 코드, 응답 헤더나 화면 위치 등
재현 가능한 웹 증거를 연결한다.
